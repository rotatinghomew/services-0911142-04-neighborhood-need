# 现场复核

先在画外完成依赖或镜像准备。服务就绪检查为 `/health`，启动不下载资料。

## 资料浏览（原有流程）

打开首页，选择调查轮次与统计边界，查看街区样本与人口交叉单元；从任一明细点开原始记录核对。保存一次当前材料，然后改动选择并重新计算，再打开刚才的记录，确认原范围仍在，最后导出。

## 小域需求估计（排班讨论流程）

1. 切换到“小域需求估计”页签，确认轮次与边界后点击“计算小域需求估计”。模型拟合与蒙特卡洛在服务端完成，同种子结果可复现。
2. 在各社区表中并排阅读模型需求人数、95%区间、模型需求率与直接估计率。无样本社区（如 A10）直接列显示“无本地样本”，借用占比100%、可靠程度“低”，行底色与证据性质文字同时提示，不与有直接证据的社区混排。
3. 打开“信息来源与边界映射影响”：确认每个新区借用了哪些旧区问卷、流向占比与样本量；存在不确定映射时阅读角点影响范围，对称区间导致零跨度时按说明理解，不把“零跨度”误读为“没有不确定性”。
4. 调整人口情景：修改全局或讨论中的系数、切换 unknown 缺口策略（均值插补/保守记0/手工给定），重新计算并比较。手工策略必须补齐全部缺口单元，否则页面给出错误提示。
5. 阅读“留出整个社区的预测检验”：核对 MRP、调整后分层、街道均值三套口径的误差与覆盖率，理解模型相对简单均值的取舍依据；该检验按整社区留出，不随机拆同社区答卷。
6. 需要留存时填写记录名称并“保存当前估计”，情景与结果一并冻结；修改情景重新计算后再打开旧记录，确认数字不随新情景变化。单元级追溯表可下钻到每个人口单元的状态、处理方式与模型需求。

上述操作的设计时长为2至4分钟，留出异常提示时间后不超过6分钟。部署故障不隐藏也不回放旧结果。统计方法、模型选择和业务结论的复核要点见 `docs/data-contract.md`。
